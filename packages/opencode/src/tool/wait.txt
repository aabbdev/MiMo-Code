Wait for something instead of polling for it.

Polling costs a whole model turn per look: `sleep 50` then check, again and again. Use
this to spend one call instead.

WHY POLLING LOOKS NECESSARY: `exec_command`'s `yield_time_ms` is a TERMINATION budget,
not a yield — a command still running when it expires is killed. A long job therefore
cannot run in the foreground, and looking at it repeatedly is the only thing left.

Prefer `until_path`: it returns the moment the artefact exists AND is non-empty, so a
job that finishes in 20 s costs 20 s. Use `seconds` only when nothing observable marks
the end. Both are bounded by `timeout_seconds`.

A timeout comes back as `met: false`, not as an error: check the job's own log, do
something else and come back, or wait again. Do not wait for something a command could
have told you — if it can report when it is done, run it and read the result.
